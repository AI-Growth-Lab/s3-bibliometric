Analyse your literature with S3

S3 maps the themes of a research field from the titles and abstracts of its papers and writes a report organised for a literature review. Export your papers from Scopus, pick how you want to run S3, and follow three or four steps.

Free and open source No coding needed Latest version on PyPI
Code and user guide: github.com/AI-Growth-Lab/s3-bibliometric · Package: PyPI Method: Bekamiri, H., Østergaard, C. R., & Timmermans, B. (2027). Semantic similarity score: A new method for mapping intellectual structures in business research. Journal of Business Research, 219, 116582. doi.org/10.1016/j.jbusres.2026.116582

Choose how to run S3

Not sure? Choose Google Colab: it needs nothing installed.

Other ways:

Google Colab

nothing to install

Colab runs Python in your browser, on Google's servers.

  1. Open colab.research.google.com → New notebook.
  2. Paste this into the first cell and press ▶. It installs S3 and asks for your Scopus file.
    !pip install -q s3-bibliometric from google.colab import files csv = list(files.upload())[0]
  3. Add a second cell, paste this and press ▶. S3 runs and the report downloads.
    import s3bib res = s3bib.run_s3(csv) res.report("s3_report.html") files.download("s3_report.html")
    The first run downloads the language model and takes a few minutes. Open the report in your browser.
Tips and if something goes wrong
  • Faster: Runtime → Change runtime type → T4 GPU before you start.
  • Your file is uploaded to Google's servers. To keep it on your computer, use another way.
  • Colab stopped or disconnected? Run both cells again; S3 starts over.
  • Jupyter on your own computer: skip the upload lines and use the file path, e.g. res = s3bib.run_s3("scopus.csv").

Claude Desktop

Mac or Windows app

You add S3 to Claude once. Claude then runs it on your computer and explains the results. S3 is an open-source library and MCP server: s3-bibliometric on PyPI, code on GitHub.

  1. Install uv, once. It downloads and starts S3 for Claude. Paste one line, then close the window.
    Mac: Terminal
    curl -LsSf https://astral.sh/uv/install.sh | sh
    Windows: PowerShell
    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
  2. In Claude, open Settings → Developer → Edit Config. It shows the file claude_desktop_config.json: open it with TextEdit (Mac) or Notepad (Windows).
    Where is Settings, and where is the file?

    Settings is in the Claude menu in the menu bar (Mac), or the ☰ menu at the top left → File (Windows). The file is here:

    Mac (Finder → Go → Go to Folder…, paste this)
    ~/Library/Application Support/Claude/claude_desktop_config.json
    Windows (paste into the File Explorer address bar)
    %APPDATA%\Claude\claude_desktop_config.json
    Or open it from Terminal (Mac; creates the file if it is missing)
    mkdir -p ~/Library/Application\ Support/Claude && touch ~/Library/Application\ Support/Claude/claude_desktop_config.json && open -a TextEdit ~/Library/Application\ Support/Claude/claude_desktop_config.json

    From PowerShell (Windows): notepad "$env:APPDATA\Claude\claude_desktop_config.json". Claude from the Microsoft Store keeps the file in another folder: use Edit Config.

  3. Paste this, save, then quit Claude completely and open it again.
    { "mcpServers": { "s3-bibliometric": { "command": "uvx", "args": ["s3-bibliometric"] } } }
    Paste rather than type (TextEdit can turn typed quotes into curly ones). If the file already has "mcpServers", add only the "s3-bibliometric" part inside it.
  4. Ask Claude, naming the tools so it uses them:
    Use the s3-bibliometric tools to run S3 on ~/Downloads/scopus.csv, label the themes and build the literature-review report.
    Claude asks which language model to use (the default is fine) and whether you have a Scopus API key.
If something goes wrong
  • Claude says it cannot find S3, or tries to install a library itself: the tools are not loaded. Check that s3-bibliometric is in the tools menu of the chat box, that the config file is valid (straight quotes, every bracket closed), and restart Claude.
  • Still no tools: Claude may not find uvx. Run which uvx (Mac) or where uvx (Windows) and put that full path in "command".
  • A language model does not download (e.g. the 1.1 GB multilingual model): download it once in Terminal or PowerShell, then ask again: uvx --from s3-bibliometric s3bib download-model multilingual.
  • Updating S3: restart Claude. If the new tools don't show, run uv cache clean s3-bibliometric first.

Claude.ai or ChatGPT

browser, phone or the ChatGPT app

These chats can't run programs on your computer, so you make the report first and the chat explains it.

  1. Make the report. The easiest way is Google Colab (nothing to install). Or, with uv installed, run in Terminal or PowerShell (change the file path):
    uvx --from s3-bibliometric s3bib report ~/Downloads/scopus.csv -o ~/Desktop/s3_report.html
  2. Open s3_report.html and click the downloads at the top: themes table, methods paragraph and reading list.
  3. Upload the report and those files to the chat, and ask:
    This is an S3 analysis of my literature. Name each theme in 3–5 words and draft the structure of my literature review, with the gaps to discuss.
Why can't the chat run S3 itself?

S3 needs to download a language model (420 MB) and run on your data. Browser chats work in a closed sandbox that can't do that. Claude Desktop and Claude Code can: they start S3 on your computer.

R or RStudio

R 4.1 or newer; results come back as data frames
  1. Install the R package once:
    install.packages("remotes") remotes::install_github("AI-Growth-Lab/s3-bibliometric", subdir = "r")
  2. Run S3 and write the report:
    library(s3bibliometric) res <- s3_run("~/Downloads/scopus.csv") s3_report(res, "s3_report.html")
  3. Work with any answer in R, for example the themes or the foundations of each theme:
    s3_communities(res) s3_answer(res, "Q8")$tables[[1]]
Tips and if something goes wrong
  • Try it first on the included example: res <- s3_run(s3_example()).
  • The first time, R sets up the matching Python library by itself (through reticulate), and the first run downloads the language model (420 MB).
  • The R package and the Python library always have the same version, so they give the same results.

Command line or Python

Terminal (Mac) or PowerShell (Windows)
  1. Install uv, once, then close and reopen the window:
    Mac: Terminal
    curl -LsSf https://astral.sh/uv/install.sh | sh
    Windows: PowerShell
    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
  2. Make the report (change the file path):

    It asks which language model to use (press Enter for the default) and whether you have a Scopus API key (answer n if not).
  3. Open s3_report.html in your browser.
In Python instead
pip install s3-bibliometric
import s3bib res = s3bib.run_s3("scopus.csv") res.report("s3_report.html")

Every answer is also a table: res.communities(), res.answer("Q8"). All functions: user guide.

If something goes wrong
  • uvx: command not found: close and reopen Terminal or PowerShell after installing uv.
  • A language model does not download: uvx --from s3-bibliometric s3bib download-model multilingual (or the model you chose) downloads it on its own, then run the report again.

What you get: a report organised for your literature review

The field at a glanceNumbers, themes, one paper per theme to read first, trends and gaps.
Theme cardsWhat each theme is about, word clouds, foundations, growth and links between themes.
Network indicatorsThe network as a whole and each paper's position: hub, connector or peripheral.
Research agendaKnowledge gaps and emerging themes for your discussion section.
Methods appendixA methods paragraph to adapt, a glossary and the validation against other methods.
DownloadsReading lists for Zotero, EndNote or Mendeley (RIS, BibTeX), themes table, PRISMA counts.

Papers in several languages · the multilingual model

S3's default model reads English. For a corpus that mixes languages, use the multilingual model (about 1.1 GB, downloaded the first time).

Google Colab: in the second cell
res = s3bib.run_s3(csv, s3bib.S3Config(model_name="multilingual"))
Claude Desktop or Claude Code: ask
Use the s3-bibliometric tools with the multilingual model to run S3 on ~/Downloads/scopus.csv.

If the download fails in the chat, download it once in Terminal or PowerShell: uvx --from s3-bibliometric s3bib download-model multilingual.

Command line: add --model multilingual
uvx --from s3-bibliometric s3bib report ~/Downloads/scopus.csv --model multilingual -o ~/Desktop/s3_report.html
R
res <- s3_run("~/Downloads/scopus.csv", model = "multilingual")
Exact, complete references · a Scopus API key

With a key from dev.elsevier.com, S3 fetches every paper's full reference list from Scopus: exact citations and bibliographic coupling, instead of matching titles in the References column. It needs your institution's Scopus access (campus, VPN or an institutional token). Never paste a key into a chat.

Google Colab: store the key under Secrets (key icon) as SCOPUS_API_KEY, then before the report
import os from google.colab import userdata os.environ["SCOPUS_API_KEY"] = userdata.get("SCOPUS_API_KEY") s3bib.enrich_citations(res)

Google's servers are off campus, so this usually needs an institutional token too.

Claude Desktop: in the config, next to "args", then restart Claude
"env": {"SCOPUS_API_KEY": "your-key"}
Claude Code: add S3 with the key
claude mcp add s3-bibliometric --env SCOPUS_API_KEY=your-key -- uvx s3-bibliometric
Command line: set the key, then add --scopus to the report command
Mac
export SCOPUS_API_KEY="your-key"
Windows PowerShell
$env:SCOPUS_API_KEY="your-key"
R: put SCOPUS_API_KEY=your-key in ~/.Renviron, restart R, then
s3_enrich_citations(res)
A hybrid map · text plus citations

S3 uses the text map by default, as in the published method. A hybrid map mixes in bibliographic coupling, co-citation or direct citation at 5–40% weight. S3 screens them and uses the best hybrid only when it improves both the silhouette and the QI of the communities; otherwise it keeps the text map. The report's Q0 shows the screening.

Google Colab: in the second cell
res = s3bib.run_s3(csv, s3bib.S3Config(map_weights="hybrid"))
Claude Desktop or Claude Code: ask
Run S3 on ~/Downloads/scopus.csv with a hybrid map.
Command line: add --map hybrid
uvx --from s3-bibliometric s3bib report ~/Downloads/scopus.csv --map hybrid -o ~/Desktop/s3_report.html
R
res <- s3_run("~/Downloads/scopus.csv", map = "hybrid")
A knowledge graph · methods, data, theories and findings

S3 can record what each paper uses and finds, as triples such as absorptive capacity → increases → innovation performance. The report then shows each theme's methods and theories, and which findings papers agree or disagree on (Q39, Q40). Upload your own triples, or let Claude or ChatGPT extract them from the abstracts. Try 30 papers first.

Claude Desktop or Claude Code: ask
Extract the knowledge-graph triples for my S3 run and show me Q39 and Q40.

Claude asks whether to use your Claude plan, your ChatGPT plan, an API key, or do it in the chat.

Command line, with your Claude plan (Claude Code installed; --backend codex uses your ChatGPT plan)
uvx --from s3-bibliometric s3bib extract-triples ~/Downloads/scopus.csv --backend claude-code -o ~/Desktop/triples.csv

Then add --triples ~/Desktop/triples.csv to the report command.

Google Colab: with an API key in Secrets, or your own file
res.extract_triples("anthropic", max_papers=30) # or res.add_triples("triples.csv")

API keys need !pip install -q "s3-bibliometric[llm]" and ANTHROPIC_API_KEY or OPENAI_API_KEY in Secrets.

R
s3_extract_triples(res, "claude-code") # or s3_add_triples(res, "triples.csv")
